## מה המערכת עושה

המערכת מיועדת לאנשי מקצוע במשרד התחבורה ומאפשרת:

1. **סקירת מצב** — מפה אינטראקטיבית של כל הצמתים בישראל, מדורגים לפי ציון סיכון משולב (תאונות + עומסי תנועה)
2. **ניתוח צומת ספציפי** — לחיצה על צומת במפה מציגה מיד פרופיל תאונות ועומסים, וזיהוי אוטומטי של תשתית קיימת
3. **ניתוח הנדסי מלא** — השוואת 9 חלופות שדרוג לפי 4 קריטריונים (בטיחות, תנועה, כלכלה, סביבה)
4. **חיזוי השפעה** — בחירת פתרון ← חיזוי מצב לפני/אחרי: תאונות, LOS, השהייה, עומסים, ROI
5. **בדיקת תכנון** — העלאת קובץ תכנון צמתים חדשים לבדיקת היתכנות

## זרימת האפליקציה (דף אחד)

### 📊 סקירה כללית
- **KPIs תאונות:** סה"כ, קטלניות, קשות, קלות, עלות שנתית
- **KPIs עומסי תנועה:** תאונות בשעות עומס, תאונות עורפיות (מדד פקק), מדד עומס ממוצע
- **ציון סיכון משולב** = תאונות (65%) + עומס (35%)
- **גרפי EDA:** שעות עומס, עורפיות לפי מחוז, scatter תאונות×עומס, top 10 עמוסים

### 🗺️ מפה אינטראקטיבית
- כל 2,992 הצמתים — צבע לפי ציון סיכון
- **לחיצה** → המפה מתקרבת לצומת + ניתוח מוצג מיידית

### 🔍 ניתוח צומת נבחר
- פרופיל CBS: תאונות, % קטלניות, % לילה, % עורפיות (פקק), % שעות עומס
- עלות כלכלית שנתית (₪3.5M לתאונה קטלנית — משרד התחבורה)
- **זיהוי תשתית קיימת** — שלוש שכבות:
  - CBS: `SUG_DEREH=5` → כיכר קיימת (אמין)
  - OpenStreetMap: כיכר / רמזור / עצור / מצלמה
  - CBS inference: `frontal_pct>25%` → עצור/כניעה

### 📋 שלב א — ניתוח המצב הקיים
פרמטרים הנדסיים מחושבים אוטומטית מנתוני CBS:

| פרמטר | חישוב | מקור |
|-------|-------|------|
| AADT | תאונות/שנה ÷ שיעור תאונות (NCHRP 17-45) | CBS |
| LOS | מדד עומס לפי HCM Table 19-8 | CBS |
| השהייה | מ-LOS + rear_pct (HCM Exhibit 19-1) | CBS |
| תורים | מהשהייה + rear_pct (HCM Queuing) | CBS |

**בדיקה:** האם נדרש שדרוג? (לפי 5 קריטריוני HCM)  
- ✅ צומת טובה → "אין צורך בשדרוג מיידי"  
- ⚠️ צומת בעייתית → המשך לניתוח חלופות

### 🏗️ שלב ב — פתרונות אפשריים (HCM / AASHTO / FHWA)
9 חלופות מדורגות לפי ציון משוקלל:

| קריטריון | משקל | מבוסס על |
|---------|------|---------|
| בטיחות | 40% | הפחתת קטלניות + פציעות + קונפליקטים |
| תנועה ותפעול | 35% | שיפור LOS + השהייה + קיבולת |
| כלכלה | 15% | ROI = (חיסכון שנתי × 5) / עלות השקעה |
| סביבה | 10% | פליטות + רעש + דלק |

### 🔮 שלב ג — בחר פתרון וחזה את השיפור
- **אופן ביצוע:** תיאור השינויים הנדרשים
- **KPIs:** עלות, חיסכון שנתי, ROI, הפחתת קטלניות, LOS חדש
- **גרפים:** תאונות לפני/אחרי + פרמטרי תפעול לפני/אחרי
- **טבלת השוואה מלאה:** 15 פרמטרים עם ✅⚠️❌

### 🏗️ בדיקת תכנון צומת חדש
- **הזנה ידנית:** קואורדינטות + פרמטרים → ציון סיכון + המלצה
- **העלאת CSV:** עשרות צמתים → הערכה אוטומטית (כולל אישור/דחייה לפתרון מוצע)

## 🤖 מודל ML (Random Forest)

```python
# X — פרופיל אתר:
features = ['תאונות', 'fatal_pct', 'serious_pct', 'night_pct', 'rain_pct',
            'pedestrian_pct', 'frontal_pct', 'rear_pct', 'rollover_pct',
            'high_speed', 'peak_pct']  # peak_pct — חדש: מדד עומס

# y — התערבות מומלצת (7 סוגים)
target = 'label_intervention'
```

| F1-Score | 74.5% |
| Precision | 76.2% |
| Recall | 79.1% |
| Feature חשוב ביותר | `rear_pct` (41.6%) |

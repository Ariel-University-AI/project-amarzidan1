## האפליקציה — דף יחיד, זרימה רציפה

### 1. לוח מחוונים — סקירה כללית
שלוש שורות KPI:

**תאונות דרכים בצמתים:**
- סה"כ תאונות בצמתים · קטלניות · קשות · קלות · עלות שנתית

**עומסי תנועה בצמתים:**
- תאונות בשעות עומס (07–09, 16–19) · תאונות עורפיות (מדד פקק) · צמתים עם עומס גבוה · מדד עומס ממוצע
- מדד עומס = rear_pct × 0.6 + peak_pct × 0.4

**ציון סיכון משולב** = תאונות (65%) + עומס (35%):
- 🔴 סיכון גבוה · 🟡 בינוני · 🟢 נמוך · סה"כ צמתים מנותחים

גרפי EDA: שעות עומס מול רגילות · תאונות עורפיות לפי מחוז · scatter תאונות × עומס · TOP 10 עמוסים

### 4. פרמטרים הנדסיים — מחושבים אוטומטית מ-CBS

**ציון מצב קיים (0–100):** בטיחות 40% + תנועה 35% + כלכלה 15% + סביבה 10%

### 5. האם נדרש שדרוג? — לפי תקני HCM
5 קריטריונים:
- LOS A–C ✓ · השהייה < 35 שנ' ✓ · 0 קטלניות + ≤1 קשות ✓ · עומס < 30% ✓ · תורים < 100מ' ✓

אם 3+ קריטריונים טובים → **✅ "הצומת במצב טוב — אין צורך בשדרוג"** + אפשרות לראות חלופות בכל זאת  
אחרת → **⚠️ "הצומת מצריכה בדיקה"** + פירוט הבעיות

## מודל ML — פרטים

```python
X = ['תאונות', 'fatal_pct', 'serious_pct', 'night_pct', 'rain_pct',
     'pedestrian_pct', 'frontal_pct', 'rear_pct', 'rollover_pct',
     'high_speed', 'peak_pct']          # peak_pct = מדד עומס חדש

y = 'label_intervention'                # 7 סוגי התערבות

model = RandomForestClassifier(n_estimators=200, max_depth=10,
                               random_state=42, test_size=0.2)
```

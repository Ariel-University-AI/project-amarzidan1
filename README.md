# מערכת תמיכה בהחלטות לשדרוג צמתים — משרד התחבורה 🚦

## תיאור הפרויקט

מערכת **תומכת-החלטה למשרד התחבורה** — מזהה, מדרגת ומציעה פתרונות לשדרוג צמתים ומחלפים בישראל לפי שני מדדים:

- **מדד תאונות** — מבוסס נתוני תאונות אמיתיים (למ"ס PUF 2021)
- **מדד עומס תנועה** — מבוסס % תאונות עורפיות + שעות עומס

לכל צומת: ציון סיכון משולב, המלצה על פתרון תשתיתי, עלות מאומתת ממכרזים, וחישוב ROI.

---

## שלוש רמות הניתוח

| רמה | שאלה | טאב |
|-----|-------|-----|
| **תיאורי** | מה קורה בצמתים? | 🗺️ מפת צמתים |
| **חיזוי** | מה הסיכון בצומת חדש/מתוכנן? | 🔮 חיזוי תשתית |
| **מנחה** | מה כדאי לעשות ובכמה? | 🔍 ניתוח צומת + 💰 תקציב |

---

## טאבים

### 🗺️ מפת צמתים (תיאורי)
- מפה אינטראקטיבית: כל הצמתים צבועים לפי ציון סיכון משולב
- ציון = תאונות (65%) + עומס תנועה (35%)
- טבלת דירוג עם ייצוא CSV
- גרפי EDA: חומרה, שעות, מחוז, סוג תאונה

### 🔍 ניתוח צומת (מנחה)
- פרופיל תאונות מלא לכל צומת
- **7 פתרונות מדורגים** עם עלות מאומתת + ROI
- שאלות על הצומת: נפח תנועה, מספר כניסות, בקרה קיימת

### 🔮 חיזוי תשתית (Predictive)
- **הזנה ידנית**: קואורדינטות + פרטי צומת → ציון סיכון + המלצה
- **העלאת קובץ**: העלה CSV עם עשרות צמתים → בדיקה אוטומטית
  - אם הוגדר "פתרון מוצע" — המערכת תאשר/תדחה

### 💰 תכנון תקציב (מנחה+)
- הכנס תקציב זמין → קבל רשימת צמתים אופטימלית
- חיסכון כלכלי צפוי (5 שנים)
- ROI כולל לתכנית
- ייצוא לExcel

### 🤖 מודל ML
- Random Forest Classifier — 79.1% Accuracy
- 11 פיצ'רים כולל peak_pct (מדד עומס)
- Confusion Matrix + Feature Importance
- חיזוי אינטראקטיבי

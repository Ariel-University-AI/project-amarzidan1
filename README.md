## 🔄 זרימת האפליקציה

```
1. סקירה כללית  →  KPIs תאונות + עומסי תנועה + ציון סיכון משולב
2. מפה           →  לחץ על צומת לניתוח מיידי (zoom אוטומטי)
3. ניתוח צומת   →  פרופיל CBS + זיהוי תשתית קיימת (OSM + CBS)
4. שלב א         →  פרמטרים הנדסיים (AADT, LOS, השהייה — מחושבים מ-CBS)
5. שלב ב         →  9 חלופות מדורגות לפי HCM/AASHTO/FHWA/NCHRP
6. שלב ג         →  בחר פתרון → חיזוי לפני/אחרי + טבלת השוואה מלאה
7. חיזוי תשתית  →  צומת חדש: הזנה ידנית / העלאת CSV
```

## 🤖 מודל ML

| פרמטר | ערך |
|-------|-----|
| אלגוריתם | Random Forest Classifier |
| n_estimators | 200 |
| train_test_split | 80/20, random_state=42 |
| Accuracy | **79.1%** |
| F1-Score | 74.5% |
| פיצ'רים | 11 (כולל `peak_pct` — מדד עומס חדש) |
| Target (y) | התערבות מומלצת (7 סוגים) |
| Feature חשוב | `rear_pct` — 41.6% |

**X (פיצ'רים):** תאונות, fatal_pct, serious_pct, night_pct, rain_pct, pedestrian_pct, frontal_pct, rear_pct, rollover_pct, high_speed, **peak_pct**

## 🏗️ מנוע ניתוח הנדסי — 9 חלופות

ציון 0–100 לכל חלופה לפי 4 קריטריונים:
- **בטיחות 40%** — הפחתת קטלניות/פציעות/קונפליקטים
- **תנועה 35%** — שיפור LOS, השהייה, קיבולת
- **כלכלה 15%** — ROI, עלות/תועלת
- **סביבה 10%** — פליטות, רעש

| חלופה | הפחתת קטלניות | עלות ממוצעת | מקור |
|-------|--------------|------------|------|
| כיכר חד נתיבית | **90%** | ₪500,000 | FHWA Roundabout Guide (2010) |
| כיכר טורבו | 85% | ₪2,500,000 | SWOV (2010), Fortuijn |
| כיכר דו נתיבית | 78% | ₪1,200,000 | NCHRP Report 572 |
| מחלף מלא | 70% | ₪100,000,000 | AASHTO Green Book (2018) |
| מחלף חלקי | 50% | ₪35,000,000 | AASHTO Green Book (2018) |
| צומת מרומזר | 30% | ₪7,000,000 | HCM 6th Edition |
